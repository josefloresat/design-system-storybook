# Layout & Shape

Las unidades usan la escala **Mobile min 360**.

## Spacing

Escala de 0 a 120px: `--spacing-0`, `--spacing-xs` (4px), `--spacing-2xs` (6px), `--spacing-s` (8px), `--spacing-2s`, `--spacing-3s`, `--spacing-m`, `--spacing-l` (16px), `--spacing-2l`, `--spacing-xl` (24px), `--spacing-2xl` (32px) y de `--spacing-3xl` (40px) a `--spacing-13xl` (120px).

## Border Radius

De `--radius-xs` (2px) a `--radius-3xl` (40px), más `--radius-full` (999px) para formas completamente redondeadas.

## Icon Size

| Token | Valor |
| --- | --- |
| `--icon-size-xss` | 12px |
| `--icon-size-xs` | 14px |
| `--icon-size-s` | 16px |
| `--icon-size-m` | 24px |
| `--icon-size-l` | 32px |

## Grid

| Tamaño | Columnas | Gutter | Margen |
| --- | --- | --- | --- |
| `xs` | 4 | 12px | 12px |
| `sm` | 8 | 16px | 16px |
| `md` | 12 | 24px | 20px |
| `lg` | 12 | 32px | 40px |

La base del sistema es `--grid-base-xs` (4px) y `--grid-base-s` (8px).

```css
.card {
  padding: var(--spacing-l);
  border-radius: var(--radius-m);
  gap: var(--grid-gutter-sm);
}
```
