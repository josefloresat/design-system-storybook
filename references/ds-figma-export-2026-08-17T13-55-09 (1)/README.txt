DS Component Exporter

Adjunta este ZIP a Codex junto con la solicitud de implementar el componente.
manifest.json resume el alcance y las advertencias.
selection/ contiene el JSON oficial exportado por Figma.
selection-tree.json facilita la lectura de layout, estilos, texto y variables.
component-properties.json contiene Component Sets, componentes e instancias.
variables.json contiene variables vinculadas y, opcionalmente, todas las variables locales.
previews/ contiene las referencias visuales PNG.
assets/ contiene SVG deduplicados detectados dentro de la selección.
